# ScamChain AI 🛡️

**AI-Powered Scam Message Detection and Awareness Platform**

ScamChain AI is a web-based platform designed to help users identify potentially fraudulent messages such as fake loan offers, bank scams, phishing messages, OTP scams, and other suspicious communications.

## 🚀 Features

* 🔍 Scam message detection
* 🛡️ Risk analysis and warning
* 🌐 Tamil and English language support
* 👤 User Registration and Login
* 📱 Simple and user-friendly interface
* 💡 Scam awareness information
* ⚠️ Suspicious message alerts
* 📊 Scam analysis results

## 🛠️ Technologies Used

* Python
* HTML
* CSS
* JavaScript
* Flask
* AI / Machine Learning
* GitHub

## 🔄 How It Works

1. User opens ScamChain AI.
2. User enters or pastes a suspicious message.
3. ScamChain AI analyzes the message.
4. The system identifies suspicious patterns.
5. The user receives a risk/result message and safety guidance.
